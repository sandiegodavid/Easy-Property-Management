# Research and experiments

These are dated investigations and candidate approaches. They describe external capabilities and future product options, not the application's current runtime. Verify changing provider/API facts before implementation.

- [General AI integration](AI_INTEGRATION_RESEARCH.md): desktop agents, built-in inference and local-model roles.
- [Local model research](LOCAL_MODEL_RESEARCH.md): feasibility and alternatives.
- [Meta Muse](META_MUSE_RESEARCH.md): reported agent/model distinction and proposed file exchange.
- [Perplexity integration](PERPLEXITY_INTEGRATION_RESEARCH.md): feasibility, benefits and setup.
- [Universal Reader](universal-reader/UNIVERSAL_READER_RESEARCH.md): experimental arbitrary-spreadsheet extraction with explicit reviewed import and independent parallel backlog.
- [Hosted demo](HOSTED_DEMO_DESIGN.md): free/low-cost hosting and proposed isolated two-operator, multi-device access; not current hosted support.
- [Hosting plan](hosting/Hosting_Plan.md): the commercial hosting plan for the Hosted tier, relay, backups and control plane.
- [Hosting plan improvements](hosting/HOSTING_PLAN_IMPROVEMENTS.md): recommendations for cost, performance, operator experience, recovery and phased infrastructure adoption.
- [Hosting plan MVP options](hosting/HOSTING_PLAN_MVP_OPTIONS.md): MVP-scoped cost and performance options, including a lower-cost Phase 1 bundle.
- [Oracle A1 deployment runbook](ORACLE_A1_DEPLOYMENT.md): ARM VM provisioning, private release installation, two isolated demo workspaces, backup/restore, and the prerequisite gate for public hosted access.

Current optional AI boundaries are in [AI governance](../modules/ai-governance.md). Proposed domain/transport delivery is in [active designs](../active/README.md); scopes and dependencies remain in [the backlog](../FEATURE_BACKLOG.md).
