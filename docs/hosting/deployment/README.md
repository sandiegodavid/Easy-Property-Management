# Deployment

Use these documents to provision a new environment or review the existing setup.
Commands that create users, releases, images or workspaces apply only to new targets.

Already set up? Use the [ongoing Google Cloud runbook](../operations/GOOGLE_CLOUD_ONGOING_RUNBOOK.md)
for routine operation and replacement releases.

1. [Deployment guide](GOOGLE_CLOUD_DEMO_DEPLOYMENT.md): Google VM and IAP, release
   installation, bounded volumes, Cloudflare routes and enrollment.
2. [Configuration contract](HOSTED_DEMO_CONFIGURATION.md): protected JSON, route
   permissions, administrator CLI and session/editing authority.

For the exact recorded installation, use the [deployment record](../operations/CLOUDFLARE_OPERATIONS.md).
For the next outstanding step, use the [qualification register](../qualification/HOSTED_DEMO_PUBLIC_ACCESS_PLAN.md).
