# Qualification

Start with the [qualification and rollout plan](HOSTED_DEMO_PUBLIC_ACCESS_PLAN.md).
It contains the single current checkpoint, evidence register, remaining gates and
completion criteria.

The [supporting reports](reports/README.md) describe individual dated tests and
their limits. [Raw evidence](../evidence/) retains machine-readable observations.
A report's fixture result is not a claim that all deployed acceptance has passed.

Use the [design](../design/HOSTED_DEMO_DESIGN.md) for requirements and numerical
targets, and the [administrator runbook](../operations/HOSTED_DEMO_OPERATIONS.md)
for recurring procedures.
