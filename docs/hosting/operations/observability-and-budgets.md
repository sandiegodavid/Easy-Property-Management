## 1. Redacted Structured JSON Logs & Secret-Leak Audit

Hosted services emit single-line JSON log records formatted by `app.platform.hosted_logging` (`component`, `event`, `severity`, `timestamp_ms`, redacted fields).

1. **Inspect guardian containment & recovery alert streams:**
   ```bash
   sudo journalctl -u epm-host-guardian.service -n 50 --no-pager
   sudo journalctl -u epm-h03-identity.service --grep="hosted_recovery_alert" -n 50 --no-pager
   ```
2. **Audit host logs for zero unredacted tokens/cookies:**
   ```bash
   sudo journalctl -u 'epm-*' --since "24 hours ago" --no-pager \
     | grep -E '(__Host-[A-Za-z0-9_.-]+=(?!\[REDACTED\])|Bearer (?!\[REDACTED\])|eyJ[A-Za-z0-9_-]{8,}\.)' \
     && echo "WARNING: unredacted token pattern found" \
     || echo "OK: zero unredacted token/cookie patterns found"
   ```
3. **Local regression gate:**
   ```bash
   cd application
   PYTHONPATH=apps/server .venv/bin/pytest \
     apps/server/app/modules/hosted_access/tests/test_h06_security_headers_and_logging.py
   ```

## 2. Live GCP Control-Plane Observability & Budget Provisioning

### 2.1 APIs, IAM, 30-Day Retention & 3 Log-Based Metrics

```bash
SA="epm-h02-host@${PROJECT_ID}.iam.gserviceaccount.com"

gcloud services enable logging.googleapis.com monitoring.googleapis.com billingbudgets.googleapis.com \
  --project="$PROJECT_ID"

gcloud projects add-iam-policy-binding "$PROJECT_ID" --member="serviceAccount:${SA}" --role="roles/logging.logWriter" --quiet
gcloud projects add-iam-policy-binding "$PROJECT_ID" --member="serviceAccount:${SA}" --role="roles/monitoring.metricWriter" --quiet

gcloud logging buckets update _Default --location=global --retention-days=30 --project="$PROJECT_ID"

gcloud logging metrics create epm_hosted_recovery_alerts \
  --description="Hosted recovery overdue/failure alerts (H05/H06)" \
  --log-filter='(jsonPayload.event="hosted_recovery_alert" OR textPayload:"hosted_recovery_alert") AND severity>=WARNING AND NOT textPayload:"\"backup_recovered\""' \
  --project="$PROJECT_ID"

gcloud logging metrics create epm_host_guardian_containment \
  --description="Host guardian container containment events (H02/H06)" \
  --log-filter='jsonPayload.event="runtime_containment_attention" OR textPayload:"runtime_containment_attention"' \
  --project="$PROJECT_ID"

# Ops Agent does not export GCE inode % used; use a 3rd log-based metric
gcloud logging metrics create epm_host_inode_headroom \
  --description='Host inode utilization > 80% alerts (H06.7)' \
  --log-filter='jsonPayload.event="host_inode_headroom_alert" OR textPayload:"host_inode_headroom_alert"' \
  --project="$PROJECT_ID"
```

### 2.2 Notification Channel, Uptime Check & `$250/mo` Before-Credit Budget

> **Gotcha:** `gcloud billing budgets create` requires `--billing-project="$PROJECT_ID"` (quota project) and `--filter-projects="projects/$PROJECT_NUMBER"` (numeric project number, not string project ID).


## 3. GCP Ops Agent on `epm-h02-host`

> **Gotcha:** Ops Agent `parse_json` requires `time_format: "%Y-%m-%dT%H:%M:%S.%L%z"` whenever `time_key: time` is configured (emitted by `cloud_plan.ops_agent_config()`).

1. Install the signed `google-cloud-ops-agent` APT package (`2.73.0~ubuntu24.04`) from Google's official signed APT repository (never `curl | bash`).
2. Write `/etc/google-cloud-ops-agent/config.yaml` (`0644`, root-owned) via `install_services.install_ops_agent_config(cloud_plan.ops_agent_config())`.
3. Enable and verify:
   ```bash
   sudo systemctl enable --now google-cloud-ops-agent.service
   sudo systemctl is-active google-cloud-ops-agent.service
   ```
4. Confirm host metrics (`disk/percent_used`, `memory/percent_used`, `cpu/utilization`) and redacted JSON logs arrive in Cloud Monitoring/Logging with zero secrets.
