Scope and limitations

Static inventory of the checked-in 341-operation OpenAPI surface, compared with
SPA source, generated workflow dispatch, dynamic URLs, backend composition,
scripts, and demo consumers. Thirty-two HTTP operations have no identified
current SPA caller. Tests and generated declarations alone are not production
usage. Absence of a repository caller does not prove an API is safe to delete;
external consumers and documented recovery/operational contracts still require
confirmation. No implementation changes or tests were performed for this inventory.

RECOMMENDED SEQUENCE

Review the seven redundant reads first, then standardize receipt lookup
conventions. Keep operational and safety APIs separate from unused-code cleanup.
Any approved removal should update OpenAPI/generated contracts, relevant tests,
and documentation without removing the underlying business/recovery guarantees.
