# Operation index

[Manual contents](README.md)

Use this index for uncommon actions. Action names below are checked against the current registered browser-form catalog on October 14, 2026. A listed action is offered only in its appropriate record/context and lifecycle; it is not necessarily a top-level button. Open the linked task chapter first, then the current owning record. Shared forms normally submit through **Save [action name]** and may require additional confirmation. Presence here does not permit bypassing a disabled action or starting a duplicate attempt.

## Unavailable and future operations

Legal/eviction matters, HOA cases, Excel/Sheets portfolio import, assistant setup, feature-specific issue-proposal review, showing workflows and broader owner accounting are not documented here as live operator controls. Dashboard snapshots/cron are not installed. Their future design or prototype presence does not make them available. Ask the product owner for the current release's qualified capabilities.

When a release adds/removes an action or changes its context, update this index and its task chapter together. Developers maintain the catalog in the generated contracts; operators should use source-screen actions rather than constructing API calls or workflow URLs.
