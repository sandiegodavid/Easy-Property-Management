# Leases and inspections

[Manual contents](README.md)

## Create, review and execute a lease

Before starting, confirm the Property/Space exists, participants have correct identities, and current occupancy/availability is accurate.

1. Open **Leasing → Set up lease → Create lease draft**.
2. Select the Space and residential/commercial type. Enter contractual dates, occupancy start and the terms the form requires.
3. Add lease participants with their effective participation dates. Correct or remove draft participants explicitly; review any removal confirmation.
4. Review rent amount/cadence, deposit agreement and term dates. Use **Replace draft rent terms** for editable draft terms.
5. Attach relevant lease documents through the document panel; wait for upload confirmation.
6. Review the full draft and choose **Execute lease** when the actual contract should be recorded. Check both Lease and Space context if a conflict is reported.
7. Follow **Review rent setup** to preview and synchronize Finance expectations. Execution does not create rent/deposit receipts.

A document upload is not execution or e-signing. Contract end and physical move-out are distinct facts. Opening an inspection failure must not conceal a recorded lease.

## Renewal and ending

Add/edit a renewal option in the Lease, then use **Decide renewal option** to record the reviewed outcome. An exercised option is not automatically a new executed successor lease; verify the records and next steps shown.

Use **End lease**, **Terminate lease** or **Void lease** only for the matching actual situation, with required dates/reasons/confirmation. Do not use Void as a shortcut for a tenant's physical move-out. Inspect both contractual history and occupancy milestones after saving.

For negotiated termination:

1. Use **Request termination** and document the request, explanation and date.
2. Add proposal versions with termination date, fees, conditions, access and other terms.
3. Use the review/acceptance action only for an actual reviewed decision; attaching documents does not imply agreement.
4. Complete the termination through its explicit completion step when conditions are met.
5. Review move-out, rent responsibility, inspection and settlement separately.

Attach case documents from the termination context. History retains proposals and decision dates. Eviction/legal-case administration is a separate planned workflow.

## Inspection templates and draft reports

1. Open **Leasing → Inspection templates** to create/edit a reusable checklist template.
2. From the intended Lease's inspections, create a move-in or move-out inspection draft.
3. Review report dates, scope and checklist. Edit the draft/checklist while permitted.
4. Enter actual observations and attach evidence to the correct observation. Record condition and relevant descriptions rather than assuming missing evidence means good condition.
5. Record acknowledgments for exactly the participants active at the walkthrough, reviewing participation dates.
6. Review all required facts/evidence, then **Finalize inspection**.

Use **Correct finalized inspection** to create a correction draft, retaining the original. Finalize the corrected record explicitly; editing input alone does not replace the finalized result.

## Compare move-in and move-out

Select the relevant reports and **Review condition comparison**. Review changed observations and source evidence. Record the operator's comparison decision. This provides evidence; it does not automatically decide tenant liability, create a deposit deduction or issue a refund.

After move-out, use **Review deposit settlement** in Money. Keep report finalization, deduction approval and actual refund recording as separate actions.

## Documents and archived evidence

Attach files from the Lease, termination case or Inspection observation so the association is correct. Unavailable content remains visible as metadata/history without an enabled download. Archive an evidence link only with the required confirmation/reason; this removes the active association, not necessarily the underlying retained file. Draft observation evidence can be archived under that review rule.

If a file response was interrupted, check the original result. Reselect identical bytes only when requested by unfinished-form recovery; selecting a similar-looking replacement file is insufficient.
