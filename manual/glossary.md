# Glossary

[Manual contents](README.md)

| Term | Meaning |
| --- | --- |
| Workspace | The external folder containing one operator's database and retained files. |
| Property / Space | Property is the reporting inventory record; Space is its rentable occupancy unit. |
| Party / identity | Reusable person/company record; owner, tenant and provider roles can share it. |
| Occupancy / availability | Whether a Space is occupied versus its recorded availability for use/letting. Unknown is not vacant. |
| Draft | A saved domain record awaiting its lifecycle decision, such as Lease execution or Inspection finalization. |
| Unfinished form | Saved input, not an official domain record or committed financial effect. |
| Receipt / original result | Rent receipt records actual money; an operation receipt records what an application command committed. They are different meanings of receipt. |
| Revision conflict | The record changed after your displayed version; review current source before applying changes. |
| Allocation | Explicit assignment of received rent to a rent expectation; not a second receipt. |
| Rent expectation | One recorded period's rent obligation, separate from payment. |
| Scheduled check | A future-dated instrument, not received income until the reviewed deposit handoff. |
| Deposit agreement / held money | Promised amount versus actual recorded security-deposit receipts/refunds. |
| Settlement | Reviewed deposit deductions/credits and refund obligation; separate from actual refund payments. |
| Owner report | A client's claim that they received rent, pending verification against Finance. |
| Quote / cost context / expense | Offered price / operational estimate or work-reported amount / actual confirmed paid spending. |
| Waiting / follow-up / reminder | External dependency context / when to revisit it / a separate reminder record. None rewrites the original deadline. |
| Coverage | Source-backed missing/review/recorded/non-applicable information, not legal compliance or physical inspection certification. |
| Captured / checked / stale | When a read was taken / a successful attention check / retained results whose currency is uncertain or invalidated. |
| Archive / void / correct | Retain inactive context / explicitly reverse the allowed record / record reviewed correction with history. |
| Retained source | Preserved submitted message/transcript/file evidence, distinct from a conversation or approved issue. |
